# Open Data Regione Toscana (dati-toscana-it)

Open Data Regione Toscana is a open data portal open-data portal for Italy running **CKAN**, exposing a standardized catalog API over ~12,382 datasets.

**URL:** [Visit APIs.json URL](https://raw.githubusercontent.com/api-evangelist/dati-toscana-it/refs/heads/main/apis.yml)

**Run:** [Capabilities Using Naftiko](https://github.com/naftiko/fleet?utm_source=api-evangelist&utm_medium=readme&utm_campaign=dati-toscana-it-api-evangelist&utm_content=repo)

## Type
- **kind:** government  ·  **software:** CKAN  ·  **version:** 2.10.4

## API
- **Open Data Regione Toscana CKAN Action API** — base `https://dati.toscana.it/api/3/action`. [Docs](https://docs.ckan.org/en/latest/api/) · [Portal](https://dati.toscana.it)
- Live endpoint verified: `https://dati.toscana.it/api/3/action/status_show` · ~12,382 datasets
